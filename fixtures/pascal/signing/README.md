# Pascal signing vectors

Copied verbatim on 2026-10-28 from an earlier Pascal client project:

- `vectors.mjs`: request-signing
  test vectors (public test seeds `[7; 32]` owner and `[8; 32]` trading key only) from
  docs.pascal.trade "Request Signing" and `pascal-python-quickstart`; sources are cited in the
  file header.
- `pascal-idl-permit.json`:
  the `permitHeader` and `placeOrderPermitBody` type nodes of Pascal's on-chain Codama IDL
  (program `3vCgc3aL1D6acmtiqtUgRSRDhep4PnVgs4jk86dGpg7j`, mainnet); provenance in its `_source`.

Added in step 1.A:

- `vectors.json`: the same values in machine-readable form (the Rust test checks each one
  against `vectors.mjs`), plus the docs' full Cancel Order and Mass Cancel vectors with their
  signatures, the second cancel signature of the docs' Cancel Orders example, and four
  place-order vectors (three **with a builder**) generated by the reference
  `pascal-sign.js` with tweetnacl 1.0.3. Pascal publishes no builder vector (decision D-003),
  so those check the Rust port against the JS reference, not against Pascal. Test builder key:
  seed `[9; 32]`.

The reference implementation is a JavaScript `pascal-sign.js` (not in this repo); its Rust port is `crates/pascal-rs/src/signing.rs`, tested by `crates/pascal-rs/tests/signing_vectors.rs`
(byte-for-byte vectors) and `tests/idl_layout.rs` (offsets and decoding from the IDL).
